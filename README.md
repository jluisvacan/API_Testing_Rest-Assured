## 📝 Overview
Automated API testing framework designed to validate RESTful web services. Built using **Java** and **REST Assured**, this repository demonstrates best practices for backend testing, including status code validation, JSON schema verification, dynamic payload generation, and authentication handling.

---

## 🎯 Key Features & Test Coverage
- **CRUD Operations Validation:** Complete coverage for `GET`, `POST`, `PUT`, `PATCH`, and `DELETE` requests.
- **Data-Driven Testing (DDT):** Test execution driven by dynamic parameters and JSON/POJO payloads.
- **Response Validation:** Assertions covering headers, response body fields, response time, and HTTP status codes.
- **Contract & Schema Validation:** Automated JSON Schema validation to ensure API payload integrity.
- **Authentication Flows:** Support for Bearer Tokens, Basic Auth, and API Keys.
